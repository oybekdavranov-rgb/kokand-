ASSETS
======

Optional media the site will use automatically if present:

  • logo.png   — university logo. NOTE: the logo actually shown on the
                 site is the one set in the Admin panel (stored in the
                 database as `logo`). This file is just a convenience copy.
  • mark.png   — favicon (the page currently uses a built-in inline icon,
                 so this is optional).
  • bg.mp4     — background video. Set its path from the Admin panel
                 (the `bgVideo` field) OR reference /assets/bg.mp4.
                 If absent, an animated gradient background is used.

  fonts/       — see fonts/README.txt for the 5 custom fonts.

Nothing here is required for the site to run — all of it degrades
gracefully.
